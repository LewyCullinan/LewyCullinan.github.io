# Lewis Scott Cullinan — portfolio

Open index.html in a browser, or serve this folder with python3 -m http.server 8000.

## Included

- Personal photograph, academic introduction, GitHub and LinkedIn links.
- Education at Liverpool John Moores University, First-Class Honours and selected module marks.
- Four project entries, including the LEO rover autonomous block sorter. SmartWater and Line Follower include interactive control demos.
- A public CV page and current PDF CV.
- Career interests and acknowledgements.

## Editing

profile.js contains your name, links, biography and career interests.
projects.js contains the four project descriptions.
index.html contains the page layout and career interests.
styles.css controls appearance and mobile layout.
briefs/ and project-notes.md contain downloadable versions of the project notes; update them alongside project copy.

The project explanations distinguish existing work from proposed extensions and do not invent measured performance. Lewis supplied the profile, SmartWater, LEO rover and drone photographs. The line follower uses a credited reference photograph of another robot.

The sidebar CV link opens cv.html, with a current PDF. The original Word CV remains in Lewis’s Downloads folder; it contains a full home address and lists 90% for Automation & IoT. The public CV uses the 95% mark Lewis supplied for this website and shows Liverpool rather than a street address. Edit build-cv.py and run it to rebuild the PDF and HTML CV together.

## Hosting

Upload the contents of this folder to your GitHub Pages repository, including .nojekyll, assets/ and briefs/. Configure Pages to serve the branch and root folder containing index.html.
Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

A private Sites preview cannot be viewed by an assessor without access. Submit an accessible URL and check it while signed out.
